# API Gateway

This API Gateway includes essential features such as token validation and introspection to ensure secure access to protected resources.

## Token Validation Fallback
This API Gateway has a token validation fallback mechanism that: 
1. Validates tokens locally.
2. Optionally introspects token status from an Identity Provider.

### Configuration
- Modify `appsettings.json` to control fallback, introspection settings.
- Ensure `TokenValidation:Fallback` configurations are enabled and correctly set.

### Middleware Behavior
- Denies requests immediately if the token is inactive or account is deactivated.
- Logs introspection calls and detected deprovisioning actions.

### Setup
1. Ensure your CI/CD platform is properly configured
2. Configure required secrets in your repository settings
3. Push code to trigger the pipeline
