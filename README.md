# Cart API - Contract Documentation

## Overview

The Cart API enables authenticated shoppers to add products to their shopping cart and view the current state of their cart, with real-time inventory validation. All requests must be authenticated (JWT Bearer). Cart contents are stored in-memory per user session, and each endpoint provides immediate, accurate inventory feedback.

---

## Authentication

All `/api/cart` endpoints require a valid JWT Bearer token via the `Authorization` header:

```
Authorization: Bearer <your-jwt-token>
```

### Obtaining a Token

Use `/api/auth/token` with your credentials to obtain a JWT token. Example request:

```http
POST /api/auth/token
Content-Type: application/json

{
  "username": "demo_user",
  "password": "mypassword"
}
```

Example Response:
```json
{
  "token": "<your-jwt-token>",
  "expires": "2024-06-13T10:59:24Z"
}
```

## API Endpoints

### 1. Add Product to Cart

**POST `/api/cart/add`**

Adds a specific quantity of a valid, in-stock product to the cart. Requires JWT authentication.

#### Request

```http
POST /api/cart/add
Authorization: Bearer <your-jwt-token>
Content-Type: application/json

{
  "productId": 101,
  "quantity": 2
}
```

##### Request Body

| Field      | Type   | Required | Description                |
|------------|--------|----------|----------------------------|
| productId  | int    | Yes      | Unique product identifier  |
| quantity   | int    | Yes      | Quantity to add (>= 1)     |

#### Success Response

- **Status:** `200 OK`
- **Body:** Returns the user's updated cart, including latest inventory/availability status for each item.

```json
{
  "cart": {
    "items": [
      {
        "productId": 101,
        "productName": "Wireless Mouse",
        "quantity": 2,
        "status": "in_stock"
      },
      {
        "productId": 102,
        "productName": "USB-C Cable",
        "quantity": 1,
        "status": "out_of_stock"
      }
    ],
    "summary": {
      "totalItems": 3,
      "inStockCount": 2,
      "outOfStockCount": 1
    }
  }
}
```

#### Error Responses

| Status | Error Code           | Message                                         |
|--------|---------------------|-------------------------------------------------|
| 400    | `ValidationError`   | Invalid input (e.g., bad productId or quantity) |
| 401    | `Unauthorized`      | Missing or invalid authentication               |
| 404    | `ProductNotFound`   | Product does not exist                          |
| 409    | `OutOfStock`        | Product is out of stock                         |

**Error Body Example:**

```json
{
  "error": "OutOfStock",
  "message": "Product is out of stock and cannot be added to cart.",
  "statusCode": 409,
  "timestamp": "2024-06-13T11:00:01Z"
}
```

### 2. View Cart

**GET `/api/cart`**

Fetches the current cart state for the authenticated user. Cart contents and item status automatically reflect the latest inventory.

#### Request

```http
GET /api/cart
Authorization: Bearer <your-jwt-token>
```

#### Success Response

- **Status:** `200 OK`
- **Body:** The cart with all products, quantities, and up-to-date availability.

```json
{
  "cart": {
    "items": [
      {
        "productId": 101,
        "productName": "Wireless Mouse",
        "quantity": 2,
        "status": "in_stock"
      }
    ],
    "summary": {
      "totalItems": 2,
      "inStockCount": 2,
      "outOfStockCount": 0
    }
  }
}
```

#### Out-of-Stock Handling

If any cart item becomes out of stock since added, its `status` will show `out_of_stock`, and the summary reflects the updated status.

#### Error Responses

| Status | Error Code         | Message                                |
|--------|-------------------|----------------------------------------|
| 401    | `Unauthorized`    | Missing or invalid authentication      |

**Error Body Example:**

```json
{
  "error": "Unauthorized",
  "message": "Authentication is required.",
  "statusCode": 401,
  "timestamp": "2024-06-13T11:00:15Z"
}
```

## Cart Data Model

### CartDTO

```json
{
  "cart": {
    "items": [
      {
        "productId": 101,
        "productName": "Wireless Mouse",
        "quantity": 2,
        "status": "in_stock"
      }
    ],
    "summary": {
      "totalItems": 2,
      "inStockCount": 2,
      "outOfStockCount": 0
    }
  }
}
```

- `items` — Array of `CartItemDTO` objects.
- `summary` — Cart summary stats.

### CartItemDTO

| Field       | Type   | Description                                              |
|-------------|--------|----------------------------------------------------------|
| productId   | int    | Product ID                                               |
| productName | string | Product name                                             |
| quantity    | int    | Number of this product in cart                           |
| status      | string | `"in_stock"` or `"out_of_stock"` (based on live inventory)|

---

## Error Handling

All error responses conform to a consistent schema:

```json
{
  "error": "<ErrorCode>",
  "message": "<Description>",
  "statusCode": <int>,
  "timestamp": "2024-06-13T11:00:01Z",
  "details": "<Optional detailed string>"
}
```

- On failure (client/server), the response always includes:
  - A logical error code and description.
  - HTTP status code.
  - Timestamp of occurrence.

- Cart reflects product availability on every retrieval.
