## Guardrail Tests
This project includes guardrail tests to ensure compliance with architectural constraints:
1. **Route Guard Test**: Verifies the absence of payment-related routes in the API. It ensures APIs exposed are strictly inventoried and adhere to compliance targets. Failures in these tests provide actionable messages for rectification.
2. **Dependency Guard Test**: Checks for dependencies associated with payment systems to avoid introducing unauthorized components.
