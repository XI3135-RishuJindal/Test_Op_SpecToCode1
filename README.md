## US-006 feature flag and stub endpoint

US-006 is guarded by a feature flag so it can be enabled/disabled without code changes or redeploys.

- Configuration key path: Features:US006:Enabled
- Equivalent environment variable: FEATURES__US006__ENABLED
  - Note: Double underscores map to nested configuration sections (FEATURES__US006__ENABLED => Features:US006:Enabled)

### Configure via appsettings.json
Add or update the following section to toggle the feature flag using configuration files:
```
{
  "Features": {
    "US006": {
      "Enabled": true
    }
  }
}
```

You can place this in appsettings.json for all environments or in appsettings.Development.json for local development only.

### Enable/disable with dotnet run (local)

- macOS/Linux (bash/zsh):
  - Enable:
    FEATURES__US006__ENABLED=true dotnet run --project ApiGateway.csproj
  - Disable:
    FEATURES__US006__ENABLED=false dotnet run --project ApiGateway.csproj

- Windows PowerShell:
  - Enable:
    $env:FEATURES__US006__ENABLED = "true"; dotnet run --project ApiGateway.csproj
  - Disable:
    $env:FEATURES__US006__ENABLED = "false"; dotnet run --project ApiGateway.csproj

Tip: You can also set ASPNETCORE_ENVIRONMENT=Development to use appsettings.Development.json.

### Enable/disable with Docker

Build the image:
- docker build -t apigateway:us006 .

Run with the feature enabled:
- docker run --rm -e FEATURES__US006__ENABLED=true -p 8080:80 apigateway:us006

Run with the feature disabled:
- docker run --rm -e FEATURES__US006__ENABLED=false -p 8080:80 apigateway:us006

If you omit the variable, the default comes from appsettings within the image.

### Current stub endpoint behavior

- When enabled (Features:US006:Enabled = true):
  - The US-006 stub endpoint is exposed.
  - It returns a stubbed response indicating the feature is under development (HTTP 501 Not Implemented with a simple JSON payload).
- When disabled (Features:US006:Enabled = false):
  - The endpoint is not exposed; requests to the route will return HTTP 404 Not Found.
