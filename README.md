# API Gateway

## Logging

The API Gateway uses Serilog for structured logging. Logs are configured to be written both to the console and to files. Sensitive information, such as full usernames, is masked in log outputs to comply with GDPR and other data protection regulations.

### Log Configuration

- **Log Level**: Default log level is set to `Information`. Overrides include higher severity for Microsoft and system logs.
- **Log Outputs**: Logs are written both to the console and file, with each log file rolled daily and retained for 30 days.
- **Sensitive Data Protection**: Sensitive fields like usernames are anonymized by replacing parts of the string with `***`.

### Security and Access 
- **Log Retention**: Files older than 30 days are automatically deleted.
- **Security Controls**: Access to logs is restricted to authorized personnel only, in compliance with company policies.

### Note
Ensure that the environment where logs are stored complies with necessary security measures to protect against unauthorized access.
