# CI/CD Pipeline

## Overview
This repository contains CI/CD pipeline configurations generated by ACE DevOps Agent.

## Files
- `.github/workflows/dependency-scanning.yml`: Workflow for dependency and container image scanning.
- `.github/security/dependency-scan-policy.yml`: Policy and allowlist for CVE and payment SDKs.
- `.github/dependabot.yml`: Dependabot configuration for package updates.

## Setup
1. Ensure your CI/CD platform is properly configured.
2. Configure required secrets in your repository settings.
3. Push code to trigger the pipeline.

## Pipeline Features
- Automated build and test
- Security scanning with automated SBOM generation and CVE checks
- Container image scanning for high/critical vulnerabilities
- Dependabot for NuGet and GitHub Actions dependencies
- Deployment automation
- Quality gates
