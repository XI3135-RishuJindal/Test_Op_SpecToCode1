## Password Policies

This system enforces strict password requirements in compliance with OWASP security best practices. All users must adhere to the following policies when creating or updating passwords.

### Password Requirements

| Requirement | Rule |
|---|---|
| **Minimum length** | At least **12 characters** |
| **Uppercase letters** | At least **1** uppercase letter (A–Z) |
| **Lowercase letters** | At least **1** lowercase letter (a–z) |
| **Numbers** | At least **1** numeric digit (0–9) |
| **Special symbols** | At least **1** special character (e.g. `!@#$%^&*`) |
| **Common passwords** | Passwords matching well-known/common password lists are **rejected** |

### Password Expiration Policy

- Passwords expire every **90 days**.
- Users will receive a notification when their password is **approaching expiration** (within 14 days of the 90-day limit).
- After expiration, users will be **required to set a new password** before accessing the system.
- The new password must not match any of the user's **previously used passwords**.

### Compliance Instructions for Users

1. **Create a strong password** that satisfies all requirements listed in the table above.
   - Example of a compliant password: `Secure#Pass9!xy`
   - Example of a non-compliant password: `password123` (too short, no uppercase, no symbol; also a common password)

2. **Do not reuse old passwords.** The system will reject any password that was previously used on your account.

3. **Update your password before it expires.** You will be notified when expiration is approaching. Log in and navigate to your account settings to change your password proactively.

4. **Never share your password.** Passwords are stored using industry-standard hashing (bcrypt) and are never accessible in plain text.

5. **If your password expires**, you will be prompted to set a new one at next login. Follow the on-screen instructions to regain access.
