## Token Exchange Process

### Overview
The token exchange process involves securely exchanging an authorization code for access, ID, and optional refresh tokens from the Identity Provider (IdP). This occurs after receiving a valid callback from the IdP with an authorization code.

### Configuration
Update `appsettings.json` with the following configuration for client credentials and redirect URI:
```json
{
  "Client": {
    "Id": "your-client-id",
    "Secret": "your-client-secret",
    "RedirectUri": "your-redirect-uri"
  }
}
```

### API Endpoint
Use the `/exchange` endpoint in `AuthController` to handle the token exchange process.

### Process
1. **Receive Authorization Code**: After successful user authentication, you will receive an authorization code via a callback from the IdP.
2. **Exchange Code for Tokens**: Use the authorization code to request tokens from the IdP's token endpoint by sending an HTTPS POST request with necessary credentials.
3. **Validate Tokens**: Once received, validate and securely store the tokens.
4. **Use HTTPS**: Ensure all communications use HTTPS to maintain security.

Ensure all sensitive information, such as tokens, is neither logged nor exposed in any URL.
