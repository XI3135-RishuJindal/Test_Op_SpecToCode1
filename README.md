## Compliance (PCI Scope)
- Position: The MVP does not store, process, or transmit Cardholder Data (CHD) or Sensitive Authentication Data (SAD) and is currently out of PCI DSS scope.
- Scope statement: See the full PCI scope statement, evidence, and governance details at docs/compliance/pci/scope-statement.md.
- Developer guardrails:
  - Do not add CHD/SAD fields to APIs, models, requests, or logs (e.g., cardNumber, pan, cvc/cvv, expiry, track1/track2, pin).
  - Logging policy: Never log request/response bodies or secrets in production; redact any potentially sensitive fields in all environments.
  - Re-scope triggers: Any proposal to add payment, checkout, billing, card handling, or PSP/gateway integrations must go through Compliance/Security review and will trigger a PCI re-scope per the governance defined in the scope statement.
