## Add Product to Wishlist

### Summary
This feature allows logged-in users of the CarePay application to add products to their personal wishlist from the product page.

### Acceptance Criteria
- **Given** a logged-in user
- **When** the user interacts with the product page
- **Then** they can add products to their personal wishlist fulfilling the specified requirements.

### Definition of Done
- Implementation must comply with the acceptance criteria and pass all necessary tests.
- UI design should be reviewed for consistency with provided mockups.
- All code is reviewed and merged into the main branch.
- Relevant documentation should be up-to-date and completed.
