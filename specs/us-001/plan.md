The implementation of the User Registration feature will involve several significant architecture decisions. We'll add new methods in the AuthController.cs to handle SSO redirects and responses. The system will need to handle the parsing of tokens received from IdPs and should implement new services/class modules to manage these operations.

Ensure authentication parameters such as client IDs and secrets are securely stored in configuration files (e.g., appsettings.json) with encryption on sensitive data. In the project's Program.cs file, additional configuration may be required to handle new authentication middleware setup for supported IdPs.

This story will also necessitate new unit tests in AuthControllerTests.cs to cover each flow, validating security and error handling. Proper INTEGRATION tests will also be needed to ensure end-to-end flow with mock IdPs. Finally, documentation updates are required to guide deployment and configuration for different environments.
