## Dependency Scanning Setup
To ensure that no unauthorized payment SDKs or libraries are included in the project, we have implemented dependency scanning in our CI pipeline. Here are the steps to set it up:

1. **Installation**: Ensure that the `dotnet-dependency-scanner` tool is installed. It is included in the Dockerfile as part of the build process.

2. **Configuration**: Dependency scanning is configured to run automatically during the CI build process. You don't need to make any additional configurations.

3. **Running Scans**: When you push code to the repository, the CI pipeline will automatically run dependency scans. You can view scan results in the CI/CD logs.

## Troubleshooting
- If the scans are failing, check the CI/CD logs for specific error messages regarding unauthorized libraries.
- Ensure that you have updated your dependencies to the latest versions as required by the `dotnet-dependency-scanner`.
