# Software Modernization — TASKS

## Prerequisites

- [ ] [S] Audit current ASP.NET Web API project(s) and catalog all controllers, routes, middleware, startup/configuration files, and dependencies
- [ ] [S] Ensure access to the source code repository and confirm that the project builds and runs in its current ASP.NET Web API environment
- [ ] [XS] Set up a dedicated feature branch for the modernization effort in version control

## Phase 1 — Preparation

- [ ] [S] Install latest stable .NET SDK and ASP.NET Core development tools appropriate for the target .NET version (e.g., .NET 7/8)
- [ ] [S] Create a new ASP.NET Core Web API project in a parallel directory structure for side-by-side development/testing
- [ ] [M] Review and document all current usages of non-C#-standard libraries/packages for compatibility with .NET Core
- [ ] [XS] Update .gitignore or equivalent to account for artifacts generated by .NET Core SDK

## Phase 2 — Core Upgrade

- [ ] [M] Migrate Models and Data Transfer Objects (DTOs) to the ASP.NET Core project and resolve compatibility issues
- [ ] [M] Refactor one Web API controller and its related routes, actions, and dependencies to ASP.NET Core conventions (attach as example/template)
- [ ] [L] Refactor remaining controllers from ASP.NET Web API to ASP.NET Core Web API, updating routing, dependency injection usage, and HTTP pipeline aspects
- [ ] [M] Refactor and migrate configuration files/settings (e.g., web.config/app.config to appsettings.json/environment variables)
- [ ] [S] Update all middleware to fit ASP.NET Core pipeline (e.g., exception handling, authentication/authorization, CORS)
- [ ] [S] Update dependency injection patterns to use ASP.NET Core’s built-in DI container

## Phase 3 — Testing & Validation

- [ ] [M] Update or port all unit and integration tests to be compatible with ASP.NET Core Web API (using xUnit, MSTest, or NUnit as appropriate)
- [ ] [S] Establish test cases for controller endpoints—ensure actual vs expected output is logged for all refactored endpoints
- [ ] [S] Perform manual functional testing using tools like Postman, Swagger UI, or similar
- [ ] [S] Validate error handling and logging are compliant with Core conventions

## Phase 4 — CI/CD & Infrastructure

- [ ] [M] Update or create build scripts/pipelines (e.g., GitHub Actions, Azure DevOps, Jenkins) for .NET Core build and test tasks
- [ ] [S] Update environment variable usage and secret management as per ASP.NET Core deployment practices
- [ ] [S] Set up automated deployment to non-production environment for ASP.NET Core project

## Phase 5 — Documentation & Rollout

- [ ] [S] Update README and architecture docs to describe new ASP.NET Core solution structure, build, and run instructions
- [ ] [XS] Document any breaking API changes or endpoint refactorings for consumers/stakeholders
- [ ] [XS] Provide upgrade guide/migration notes for teams involved in future maintenance

## Post-Migration Cleanup

- [ ] [S] Remove legacy ASP.NET Web API project files and unused assets/configs from the codebase
- [ ] [XS] Archive or backup the original solution in accordance with project retention policies
- [ ] [XS] Close/merge the modernization feature branch and communicate project completion to the team
